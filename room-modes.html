Room modes

This tool gives the resonance frequencies (modes) of a rectangular room. Use it to find the low frequencies that a bass absorber must control.

How to use

  1. Type the length, width and height of the room.
  2. Type the maximum frequency for the list.
  3. Type the reverberation time if you want the Schroeder frequency.
  4. Look for frequencies with many modes close together, or with large gaps. These frequencies can sound uneven.

Description

Sound reflects between the walls of a room. At some frequencies the reflections make standing waves. These are the room modes. At a mode, the sound level changes much from one position to another position.

Axial modes use two parallel surfaces. They are usually the strongest. Tangential modes use four surfaces. Oblique modes use all six surfaces and are usually the weakest.

Above the Schroeder frequency, many modes overlap and the sound field is approximately diffuse. Below it, single modes are important.

Method

f = (c/2) √((n_x/L)² + (n_y/W)² + (n_z/H)²), n = 0, 1, 2, … Schroeder frequency: f_s = 2000 √(T / V)

Limits

  • The room is a rectangular box with rigid walls. Real walls are not fully rigid, so real modes are slightly different.
  • The tool does not show the strength of each mode.
  • Openings, furniture and non-parallel walls change the modes.
