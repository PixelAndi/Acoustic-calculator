How to use

  1. Select how the room is used. This sets the target reverberation time.
  2. Type the length, width and height of the room.
  3. Select how you know the room now. A measured RT60 gives the best result. If you cannot measure, select a description. The description uses a rough assumption.
  4. If you have a product in mind, click "Add a product" and type the values from its data sheet.
  5. Read the recommendations and the list of solutions. Click a solution to see the result on the chart.
  6. Click "Add the selected solution to the project" to keep the plan.

How the advisor works

  1. It calculates the equivalent absorption area of the room now: A = 55.26 V / (c T), from the measured or assumed values.
  2. It calculates the absorption area for the target: A_target = 55.26 V / (c T_target).
  3. The difference is the absorption to add in each octave band.
  4. For each treatment it uses the diffuse-field absorption coefficient from the calculators on this site (or your data sheet values).
  5. It finds the area of one treatment, or of two treatments together, that gives the reverberation time nearest to the target (least squares on the relative error, divided by the tolerance of each band; bands without a requirement are not used; areas not negative).
  6. It sorts the solutions: first the solutions within your maximum area, then by the number of bands in the target range, then by the largest deviation.

If the requirement is a maximum (ANSI S12.60, DIN 18041 group B), the advisor aims 10 % below the maximum as a design margin.

The panels cover hard surfaces. The advisor assumes that the absorption of the covered surface is small and does not subtract it.

Limits

  • The Sabine formula assumes a diffuse sound field. In small rooms, below the Schroeder frequency, room modes are more important than the reverberation time.
  • Shop products use published data: measured values where they exist, or a published absorption class. A class gives only one number (αw). The advisor then uses the ISO 11654 reference curve at that αw as an example spectrum, and 0 at 125 Hz. The real product can be different. Type the data sheet values in "My products" for a reliable result.
  • Furniture is not counted. For values, see the furniture list.
  • The advisor does not know about prices or offers. Type a price per m² if you want to compare costs.
  • The position of the treatment is important. The advisor gives general rules for the position. It does not calculate it.
  • After you install the treatment, measure the room again .
